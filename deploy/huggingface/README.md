# WellQuery

Ask general questions about diabetes, kidney health and diabetes medicines. Answers come only from 15 NIDDK articles, and each one shows the passage it came from.

- **Quick answer** shows the matching sentences exactly as written. It's fast.
- **AI summary** uses a small language model to write a short answer from the same sentences. On this free server it can take up to a minute.

Emergency and personal dosing questions are refused.

This is a university project, not medical advice. Health content is from the [National Institute of Diabetes and Digestive and Kidney Diseases](https://www.niddk.nih.gov/), reused under its [copyright policy](https://www.niddk.nih.gov/copyright). It is not endorsed by NIDDK.
